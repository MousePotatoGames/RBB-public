# FIRST_PLAYABLE — RUMBLE BALL

> First Playable = 핵심 재미를 직접 플레이로 판정할 수 있는 최소 빌드.
> MVP(해커톤 제출 빌드)가 아니다. 이 빌드로 [PLAYTEST_HYPOTHESES.md](PLAYTEST_HYPOTHESES.md)를 검증한 뒤 MVP 잔여 기능을 진행한다.

## 검증할 핵심 재미

[GAME_OVERVIEW](../Game/GAME_OVERVIEW.md)의 세 축 전부:

1. **조작** — 관성 있는 공을 굴리는 것 자체가 재미있는가
2. **조립** — 무기가 공 표면에 실제로 붙고, 부착 위치가 의미를 갖는가
3. **파괴** — 속도·충돌·회전 무기가 적 무리를 부수는 감각이 전달되는가

+ 코어 루프의 성장 축(경험치→레벨업→패시브)이 90초 안에서 작동하는가 (사용자 결정으로 포함)

## 세션 정의

- **시작 상태**: 그레이박스 원형 아레나 중앙, 매끈한 코어볼, 무기 없음, Lv1, HP 100. 스폰 즉시 조작 가능, 5초 내 첫 드론 접근.
- **종료 상태**: 90초 생존 → Victory / HP 0 → Defeat. 결과 화면(생존 시간·처치 수·도달 레벨·획득 무기)에서 원클릭 재시작.
- **세션 타임라인 (TEMPORARY)**: 무기 캡슐 0:10 / 0:35 / 1:00 스폰(랜덤 순서·중복 없음, WPN-005), 드론 밀도 5마리 → 90초 시점 25마리로 선형 증가.

**완료(Done) 조건** — 아래 전부 충족 시 First Playable 달성:

1. 컴파일 에러·콘솔 에러 0건으로 에디터에서 실행된다
2. 90초 세션을 승리·패배 양쪽으로 완주할 수 있다
3. 아래 수동 체크리스트 전 항목 통과
4. 재시작 3회 연속 후에도 상태 누수 없음 (풀, 이벤트, 시간)

## Scope Risks

- 사용자 결정으로 기본 제외 대상 2건이 FP에 포함됨 — **무기 3종 전부**(최소 검증은 2종으로 가능), **성장 시스템 전체**(XP·레벨업·패시브 + 전용 UI). FP 도달이 그만큼 늦어지며, 조작감 검증(HYP-001)이 뒤로 밀리지 않도록 DEVELOPMENT_ORDER의 단계별 플레이 확인을 지킬 것.
- 90초 밀도 곡선은 TEMPORARY — 3:30 MVP 곡선(기획서 9.1)과 별개이므로 MVP 전환 시 재작성 필요.

## 수동 체크리스트 (완료 조건 3번)

- [ ] 카메라를 어느 방향으로 돌려도 WASD 이동이 카메라 기준으로 일관된다 (MOVE-001)
- [ ] 최대속도 부근에서 조향이 둔해지고 관성이 느껴진다 (MOVE-003)
- [ ] 대시가 쿨다운 중 재발동되지 않고, 발동 시 즉시 럼블 단계 진입한다 (DASH-001, SPD-001)
- [ ] 같은 드론에 한 번의 충돌로 피해가 1회만 들어간다 (DMG-002)
- [ ] 저속 접촉과 고속 충돌의 피해·넉백 차이가 눈에 보인다 (DMG-001, SPD-001)
- [ ] 점프 낙하로 드론 위에 떨어지면 피해가 들어간다 (DMG-004)
- [ ] 캡슐 접촉 각도에 따라 무기가 다른 슬롯에 붙고, 표면 노멀 방향으로 정렬된다 (WPN-001, WPN-002)
- [ ] 캐논이 포신 각도가 맞을 때만 발사된다 — 뒤쪽 적에게는 쏘지 않는다 (CAN-001)
- [ ] 스파이크 부착 부위로 충돌할 때만 추가 피해가 발생한다 (SPK-001)
- [ ] 테슬라가 부착점 근처 최근접 적 1기에게 주기 공격한다 (TES-001)
- [ ] 미획득 캡슐이 사라지지 않고 비컨이 멀리서 보인다 (WPN-006)
- [ ] 레벨업 시 게임이 완전 정지하고, 선택 후 0.2초 내 재개된다 (LVL-001)
- [ ] 같은 패시브 반복 선택 시 강화되고 3단계에서 카드가 제외된다 (PAS-004)
- [ ] HP 0 → Defeat, 90초 생존 → Victory, 동일 프레임 판정 충돌 없음 (FP-001, LOSE-001)
- [ ] 재시작 후 무기·레벨·HP·타이머·적이 전부 초기화된다
