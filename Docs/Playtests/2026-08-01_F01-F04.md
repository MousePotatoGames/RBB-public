# Playtest — F01~F04 (첫 조작감 확인)

- 날짜: 2026-08-01
- 빌드: FirstPlayable.unity (에디터 플레이), F01 이동 / F02 카메라 / F03 점프·대시 / F04 속도 단계
- 플레이어: 개발자 본인 (1회차)

## Observation (플레이어가 말한 그대로)

| # | 항목 | 발화 |
|---|---|---|
| O1 | 공 조작 | "조금 답답해" |
| O2 | 고속 선회 | "딱 좋아" |
| O3 | 점프 | "좋아" |

## Hypotheses

### O1 "조금 답답해" — 이번 실험 대상

원인 후보 (확인 순서):

1. **가속 시간이 길다** — `timeToMaxSpeed = 1.2s`(가속도 10 m/s²). 최고 속도·고속 선회는 좋다고 했으므로 문제는 **초기 반응** 쪽일 가능성이 가장 높다.
2. **각속도 감쇠로 인한 저항** — `angularDamping = 1.5`. 구체는 접촉 마찰로 회전과 직선 운동이 결합되는데, 회전이 과하게 감쇠되면 마찰이 지속적인 제동으로 작용해 "진흙 위를 구르는" 느낌을 만들 수 있다.
3. **입력 지연** — 입력을 `Update`에서 읽어 `FixedUpdate`에서 적용한다(버퍼 없음). 최대 1프레임 지연. 위 둘보다 영향은 작다.

O2·O3·O5가 모두 "좋다"이므로 조향 감쇠(0.4)·점프·카메라 파라미터는 **건드리지 않는다**.

### O4 "감이 안 잡히네" — 튜닝하지 않음 (판단 보류)

대시의 존재 이유는 고속 충돌 공격(DMG-001 대시 배율)과 긴급 회피다. **지금은 부딪힐 적도, 피할 위협도 없어서** 플레이어가 판단할 근거 자체가 없다. 수치를 지금 만지면 근거 없는 튜닝이 된다.
→ F05(드론)·F06(충돌 전투) 이후 재평가. 쿨다운 1.8s의 적정성도 그때 판단.

### O6 "파티클 같은 효과" — 이미 계획됨, 스코프 유지

기획서 5.4·11.2의 완성형 VFX(먼지 → 궤적 → 발광·잔상 → 전기 아크)는 **P08**로 이미 분리되어 있다. F04는 "단계가 읽히는가"만 목표였고 그건 충족됐다.
→ 스코프 변경 없음. First Playable 검증 후 P08에서 처리.

## Next Experiment (EXP-001)

**한 변수만 변경**: `BallMovementConfig.timeToMaxSpeed` **1.2s → 1.0s**

- 변경하지 않는 것: 최대속도(12), 조향 감쇠(0.4), 공중 조향(0.35), 점프·대시 전 항목, 카메라 전 항목
- 1.0s는 MOVE-005의 권장 범위(1.0~1.5) 하단 — 규칙을 벗어나지 않는 최소 변경
- 이걸로 부족하면 EXP-002에서 `angularDamping` 1.5 → 0.8 (가속 시간은 되돌리고 하나만 다시 변경)
- 3회 실험해도 해소되지 않으면 수치가 아니라 설계를 의심할 것 (game-feel §5)

## Success Criteria (변경 전에 작성)

1. 정지 상태에서 입력했을 때 "붙는" 반응이 느껴진다 — 더 이상 "답답"하지 않다
2. 관성이 사라지지 않는다 — O2("고속 선회 딱 좋아")가 유지되어야 한다
3. 입력을 놓았을 때 여전히 미끄러지듯 굴러간다 (MOVE-001 관성 원칙)
4. 위 3개가 동시에 만족되지 않으면 실험 실패로 기록하고 EXP-002로 넘어간다

## Result (EXP-001) — 성공, 값 확정

- 적용: 2026-08-01, `timeToMaxSpeed` 1.2 → 1.0 (가속도 10 → **12 m/s²**), 다른 값 전부 불변
- 재플레이 발화: **"이제 딱 좋아"**
- 성공 기준 판정:
  1. 초기 반응 붙음 — **충족** (답답함 해소)
  2. 고속 선회 유지 — **충족** (O2 관련 파라미터를 건드리지 않았고 불만 없음)
  3. 관성 유지 — **충족** (감속 로직은 변경되지 않음, 물리 감속만 사용)
- 결론: 원인 후보 1(가속 시간)이 맞았다. 후보 2(각속도 감쇠)·3(입력 지연)은 **검증 불필요** — EXP-002는 실행하지 않음
- 후속: F01 스펙 튜닝 표 갱신 완료. MOVE-005 권장 범위(1.0~1.5) 내 변경이라 GAME_RULES 갱신 불필요
