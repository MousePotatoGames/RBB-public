# GLOSSARY — RUMBLE BALL

프로젝트 전용 용어. 코드, 문서, 대화에서 이 이름을 일관되게 사용한다.

| 용어 | 정의 |
|---|---|
| **코어볼 (Core Ball)** | 플레이어가 조작하는 구체. 시작 시 매끈한 에너지 코어 상태 |
| **럼블 (RUMBLE)** | ① 최고 속도 단계 (95% 이상 또는 대시 중, SPD-001) ② 연속 처치 표시 `RUMBLE xN` |
| **속도 단계 (Speed Tier)** | 저속/중속/고속/럼블 4단계. 충돌 피해 배율과 VFX를 결정 (SPD-001) |
| **충돌 정면도** | 플레이어 이동 방향과 적 방향 벡터의 내적. 충돌 피해 계수 (DMG-001) |
| **무기 캡슐 (Weapon Capsule)** | 전장에 스폰되는 무기 획득 아이템. 접촉 시 장착 연출 시작 (WPN-001) |
| **부착점 (Attachment Point)** | 무기가 실제로 붙는 공 표면 위치. 표면 노멀이 무기 기준축 (WPN-002) |
| **크러셔 스파이크 (Crusher Spike)** | 무기 1: 근접 돌파형. 큰 쐐기 3~5개, 접촉 추가 피해 (SPK-001) |
| **리볼버 캐논 (Revolver Cannon)** | 무기 2: 중거리형. 포신 각도가 맞을 때만 발사 (CAN-001) |
| **테슬라 링 (Tesla Ring)** | 무기 3: 안정형. 부착점 근처 적에게 주기적 번개 (TES-001) |
| **패시브 (Passive)** | 레벨업 시 선택하는 영구 강화. 강화 외피 / 고밀도 코어 / 자기장 증폭 3종 |
| **경험치 오브 (XP Orb)** | 적 처치 시 드랍, 근접 시 흡수되는 경험치 (XP-001) |
| **스크랩 드론 (Scrap Drone)** | 적 1: 물량형 직선 추적 (ENM-001) |
| **램 비틀 (Ram Beetle)** | 적 2: 예고 후 돌진형 (ENM-002) |
| **아이언 브루트 (Iron Brute)** | 적 3: 넉백 저항 탱커 (ENM-003) |
| **오버로드 코어 (Overlord Core)** | 보스. 플레이어보다 거대한 폐기 전투 코어 (BOSS-001) |
| **웨이브 디렉터 (WaveDirector)** | 경과 시간·적 수·레벨 기준으로 스폰 예산을 관리하는 시스템 (WAVE-001) |
| **코스믹 정크 아레나 (Cosmic Junk Arena)** | 유일한 맵. 폐기 우주 구조물 위 원형 전투 경기장 |
| **장착 연출 (Assembly Sequence)** | 무기 획득 시 감속→분해→흡수→조립→점화→충격파 연출 (WPN-001) |
| **히트 스톱 (Hit Stop)** | 타격 순간 0.05~0.1초 시간 정지 연출 |
| **광폭화 (Berserk)** | 3:30 시점 보스 생존 시 진입하는 보스 강화 상태. 결판까지 무제한 유지 (WIN-002) |
| **부착 슬롯 (Attachment Slot)** | 구체 표면에 사전 정의된 무기 부착 위치. 캡슐 접촉 지점에서 가장 가까운 빈 슬롯으로 스냅 (WPN-001, WPN-001a) |
| **First Playable** | 핵심 재미를 증명하는 최소 플레이 가능 빌드 (FirstPlayable 워크플로 용어) |
