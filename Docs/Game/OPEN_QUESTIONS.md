## Q7. 경기장 형태와 코어 색상 (경미 — 아트 제작 시점까지 결정)

- 관련: GAME_OVERVIEW, 아트 디렉션
- 경기장 바닥: 원형 vs 육각형 (기획서 10.2 "원형 또는 육각형")
- 플레이어 코어 기본색: 밝은 백색 vs 주황 (기획서 10.4)
- 게임플레이 규칙에는 영향 없음. 맵/아트 Feature 착수 전에 확정하면 됨.
