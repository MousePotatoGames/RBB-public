## 한 문장 소개

- Status: CONFIRMED

플레이어가 코어볼을 직접 굴려 무기를 표면에 장착하고, 회전하는 무기와 고속 충돌로 적 무리를 돌파하는 3D 물리 액션 로그라이트.

| 항목 | 값 | Status |

## 플레이어 역할과 판타지

- Status: CONFIRMED
- 역할: 매끈한 에너지 코어볼. 무기를 주워 표면에 조립하며 "굴러가는 전투병기"로 성장한다.
- 시점: 가까운 3인칭 쿼터뷰 (플레이어를 화면 세로 하단 40~45%에 배치)
- 판타지: 처음엔 작고 매끈한 코어 → 후반엔 가시·캐논·테슬라 링이 덕지덕지 붙은 거대 전투병기

## 핵심 재미 (세 축)

- Status: CONFIRMED

1. **조작의 재미** — 관성을 가진 공. 경로·속도·회전 방향을 함께 관리. 관성은 리스크와 숙련도의 원천.
2. **조립의 재미** — 무기가 UI 슬롯이 아니라 공 표면에 실제로 붙고, 부착 위치가 실루엣과 공격 방향을 바꾼다.
3. **파괴의 재미** — 속도 붙은 공이 적 무리를 가르고 날린다. 무기 공격과 충돌 공격이 동시에 발생.

## 절대 원칙 (디자인 제약)

- Status: CONFIRMED

1. 공격 버튼을 만들지 않는다. 이동·회전·충돌 자체가 공격이다.
2. 속도는 공격력과 위험을 동시에 높인다.
3. 모든 무기는 공 외곽 실루엣을 명확히 변화시킨다.
4. 무기 성능보다 장착 순간과 실제 회전이 먼저 읽혀야 한다.
5. 기능 수보다 타격 반응과 성장 가시성 우선.
6. 자동 공격은 플레이어 움직임과 완전히 분리되면 안 된다.
7. 첫 판에서 핵심 경험을 전부 볼 수 있어야 한다.

## MVP 스코프

### 포함 (IN)

- Status: CONFIRMED
- 맵 1개 (코스믹 정크 아레나), 플레이어 1종
- 무기 3종 (크러셔 스파이크, 리볼버 캐논, 테슬라 링), 무기당 2단계
- 패시브 3종 (강화 외피, 고밀도 코어, 자기장 증폭)
- 일반 적 3종 (스크랩 드론, 램 비틀, 아이언 브루트), 보스 1종 (오버로드 코어)
- 경험치·레벨업, 타이틀·HUD·결과 화면, 첫 플레이 인게임 튜토리얼
- Web 빌드 (50MB 이하 목표, 60fps 목표/최소 30fps)

### 제외 (OUT)

- Status: EXCLUDED
- 캐릭터 선택, 여러 맵, 영구 성장, 골드·상점, 업적, 세이브 데이터
- 로그인, 온라인 랭킹, 멀티플레이
- 5개 이상의 무기·패시브, 모바일 터치 조작, 절차 생성 맵, 퀘스트
- 실시간 생성형 AI API, ECS 전환, 전체 다국어 대응

## 성공 조건 (해커톤 기준)

- Status: CONFIRMED
1. 링크 클릭만으로 설치 없이 실행
2. 시작 후 15~20초 안에 "무기가 공에 실제로 붙는다"는 차별점 전달
3. 속도·회전이 전투에 영향을 준다는 사실이 조작만으로 전달
4. 3분 30초 동안 외형·전투 밀도·공격 방식이 단계적으로 성장
5. 스크린샷 한 장으로 다른 뱀서라이크와 구별
6. AI 활용·에셋 라이선스 증빙 가능
