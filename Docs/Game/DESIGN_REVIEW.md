# Design Review

- 검토 대상: Docs/Game/ 6종
- 검토자: Claude (FirstPlayable Phase 2)
- 1차 리뷰 및 결정 반영: 2026-07-30 (재검증 완료)

## Passed

- **코어 루프 반복성** — CORE_LOOP의 1→2→3(굴리기→충돌→처치·경험치)이 초 단위로 닫힌 내부 루프를 이루고, 4~6(패시브·무기 조립)은 세션 단위 외부 루프로 내부 루프에 합류한다. 마지막 단계가 첫 단계(경로 선택)로 되돌아간다.
- **성공/실패 조건 무결성** — WIN-001(보스 처치만이 승리), LOSE-001(HP 0, 동시 사망 시 승리 우선), WIN-002(광폭화 무제한 연장)로 시간 초과·동시 사망까지 모든 종료 경로가 닫혀 있다.
- **실질적 선택 존재** — 돌파 vs 회피, 대시의 공격/회피 이중 용도(DASH-001), 캡슐 접촉 각도 = 부착 슬롯 선택(WPN-001), 패시브 3계열 × 3단계 빌드(PAS-001~004). 낙하 충돌(DMG-004)로 점프도 전술 선택지가 됐다.
- **규칙 간 모순 없음** — 1차 발견된 C1(동시 사망), C2(낙하 충돌 무효화)는 해소됨. DMG-001 정면도 하한 클램프로 음수·제로 피해 경로도 차단.
- **플레이 검증 가능성** — 기획서 21.5 플레이테스트 질문 7개와 21.6 목표 지표가 정량 기준을 제공. HP-002·XP-002 TEMPORARY 수치표가 생겨 "첫 무기 획득 전 사망 금지" 같은 제약도 이제 수치로 검증 가능하다.
- **UNRESOLVED/PROPOSED 누출 없음** — 게임플레이 규칙은 전부 CONFIRMED (수치는 TEMPORARY로 명시). 남은 UNRESOLVED는 Q7(경기장 형태·코어 색상)뿐이며 아트 착수 전까지만 결정하면 되는 경미 항목.
- **제외 스코프 명시성** — GAME_OVERVIEW의 EXCLUDED 16항목 + "6일차 이후 기능 추가 금지"로 이중 잠금.
- **핵심 재미 기여도** — 모든 시스템이 조작/조립/파괴 세 축 중 하나 이상에 직접 기여. 군더더기 없음.

## Scope Risks

구현 단계에서 감시할 항목 (설계 결함 아님):

- **R1. 무기 장착 연출 (WPN-001의 8단계 시퀀스)** — 사실상 미니 컷씬. P0에서는 "슬롯에 즉시 등장 + 플래시" 스텁으로 시작하고, 풀 연출은 별도 Feature로 분리할 것.
- **R2. 물리 조작감 튜닝의 개방성** — MOVE-005 범위 안에서 1일차 타임박스 준수. 범위 밖 실험 금지 (기획서 25장 1순위 리스크).
- **R3. 고밀도 코어의 이중 증폭** — PAS-002가 속도와 충돌 피해를 동시에 올리는데 속도는 이미 DMG-001의 배율 항. 지배 전략 가능성 — 수치 확정 시 감시.
- **R4. 보스 최종 충돌 연출** — 브루트 재사용 원칙 준수, 패턴 2개 우선 (기획서 8.5).
- **R5. WIN-002 연장 구간의 웨이브 예산 미정의** — 웨이브 표가 3:30에서 끝남. 구현 시 WAVE-001에 연장 구간 행(마지막 구간 유지 수준)을 TEMPORARY로 추가.
