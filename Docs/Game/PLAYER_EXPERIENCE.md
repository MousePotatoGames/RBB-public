# PLAYER_EXPERIENCE — RUMBLE BALL

## 플레이어가 가장 먼저 이해해야 할 것

- Status: CONFIRMED

> "공에 주운 무기가 실제로 붙고, 구르면서 그 무기가 작동하는 뱀서라이크구나."

- 시작 후 15~20초 안에 첫 무기 장착으로 이 차별점이 드러나야 한다.
- 공격 버튼이 없다는 사실이 설명 없이 자연스럽게 이해되어야 한다.

## 감정 곡선 (3분 30초 세션)

- Status: CONFIRMED

| 구간 | 의도한 감정 |
|---|---|
| 0:00~0:20 | "공을 굴리는 감각이 예상보다 좋다." |
| 0:20~1:00 | "무기가 정말 공에 붙고 회전한다." |
| 1:00~2:00 | "속도와 무기 배치가 전투에 영향을 준다." |
| 2:00~2:30 | "내 공이 전투병기로 완성되고 있다." |
| 2:30~3:30 | "적 무리와 보스를 정면으로 부수는 장면이 강렬하다." |

## 조작 감각 목표 (Feel Targets)

- Status: CONFIRMED
- 실제 물리 위에 얹은 **읽기 쉬운 아케이드 물리** — 미끄럽거나 답답하면 핵심 재미 붕괴 (최우선 리스크)
- 관성은 리스크와 숙련의 원천이어야 하고, 조작 불능감을 주면 안 된다
- 속도 상승이 몸으로 느껴져야 한다: 먼지 → 바닥 궤적 → 발광·잔상 → 전기 아크 + FOV 변화
- 대시 순간 FOV 확대, 히트 스톱 0.05~0.1초, 사건 크기에 비례한 화면 셰이크 (지속적 미세 흔들림 금지)

## 피드백 우선순위

- Status: CONFIRMED

1. 입력에 대한 이동 반응
2. 충돌 방향과 힘
3. 적 피격·사망 반응
4. 무기 발동 상태
5. 속도 단계
6. 플레이어 피격과 위험
7. 점수·처치 표시

## 실패의 전달 (납득 가능한 죽음)

- Status: CONFIRMED
- 패배 원인은 공격 예고, 위험 색상, 충돌 방향으로 납득 가능해야 한다.
- 모든 위험 행동은 색 / 바닥 표시 / 준비 동작 중 최소 2가지로 예고 (ENM-004).
- 색 언어: 공격 예고 = 노랑·주황, 치명적 위험 = 선명한 빨강, 적 = 마젠타·붉은색, 플레이어 에너지 = 시안.
- 피격 무적(HP-001)으로 연속 접촉 즉사 방지.

## 재도전 동기 (Retry Drivers)

- Status: CONFIRMED
- 3분 30초 단세션 + 결과 화면에서 원클릭 재시작 (0.2초 이내 재개 원칙과 동일한 즉시성)
- 매 판 달라지는 완성형 공의 외형 — 부착 위치·패시브 선택이 만드는 변화
- 결과 화면 기록: 생존 시간, 처치 수, 최고 RUMBLE 연속 처치, 도달 레벨, 획득 무기
- 목표 지표: 첫 판 완주율 40~60%, Retry 선택률 35% 이상

## 학습 설계 (튜토리얼)

- Status: CONFIRMED
- 별도 튜토리얼 스테이지 없음. 첫 플레이에서만 WASD → Space → Shift 안내를 순서대로 노출, 입력 확인 즉시 제거.
- 첫 30초는 학습 구간이지만 전투가 비어 보이면 안 된다.
- 첫 무기 획득 전 사망 금지 (난이도 안전장치).

## 가독성 원칙

- Status: CONFIRMED
- 후반 시각 혼잡(적·투사체·번개·파편·궤적) 속에서도 플레이어와 위험 요소는 항상 구분 가능해야 한다.
- 실루엣과 Emission 대비 우선, 머티리얼 팔레트 8~12색 제한.
- 무기 부착 위치가 읽히는 카메라 거리 유지 (가까운 3인칭 쿼터뷰).
